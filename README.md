# Calendário do Advento 🎄

Abrir `index.html` no browser. Cada porta só abre a partir das 00:01 (hora de Portugal) do seu dia.

- **Editar conteúdo:** só o ficheiro `prendas.js`.
  - Em cada prenda física preenche `pista` (onde a escondeste) e escreve o `codigo` na etiqueta da prenda.
  - Dia 20 (jogo): põe `link` e/ou `imagem` (ex: `img/jogo.jpg`, ficheiro dentro da pasta `img/`).
- **Testar antes de dezembro:** abre `index.html?teste=renas-voadoras-2026`. Tudo fica desbloqueado e o progresso de teste
  é guardado à parte (há um botão para apagar).
- **Publicar:** arrasta esta pasta para https://app.netlify.com/drop (grátis) ou ativa o GitHub Pages, e envia-lhe o link.
